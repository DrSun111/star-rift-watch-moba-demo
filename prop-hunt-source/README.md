# 灯影捉迷藏

双人3D变形躲猫猫。前端由 GitHub Pages 发布，房间服务在 Supabase 新加坡区域运行。所有画面资源和 Three.js 引擎随游戏一起发布，无公共素材 CDN 依赖。

## 游玩

一人创建房间，将六码或邀请链接发给朋友；另一人输入同一码加入。双方选择角色并准备，由房主开始。电脑使用 WASD/方向键移动，右键拖动转动视角，滚轮缩放；手机使用摇杆和右侧拖动。

- 躲藏者有20秒准备，靠近物件按 E 变形，F 恢复人形，Q 使用技能。
- 寻找者在随后180秒内寻找；每个60秒窗口补充为5次攻击，不累计。左键点击物件攻击，或空格向准星攻击。
- 命中一次，寻找者立即获胜；时间结束，躲藏者获胜。技能不会抵消命中。
- 断线超过25秒或退出则对方获胜。双方同意再来一局后自动交换攻守并随机选择场景。
- 三个地图：灯火集市、浮光花园、星港码头。每局物件分布由服务器种子生成。
- 躲藏者：风叶灵（加速）、镜影师（两个诱饵）、静语者（消除并隐藏脚印及方位提示）。寻找者：追迹侦探（大致方向与冷热提示）、灯塔巡者（10米内照影）、疾风游侠（加速）。

## 结构

- 此目录的前端文件被 Vite public 目录原样复制至部署产物，无需更改原有主应用。
- 房间后端与数据库模式放在同名 `prop-hunt-source/server` 目录。成员身份用高熵令牌验证，数据库只保存 SHA-256 摘要；服务密钥不进入客户端。
- 移动、碰撞、胜负、技能和攻击额度逻辑共用 `shared.js`。服务器以版本号比较更新处理同时操作；重复事件不会重复扣除攻击次数。
- 前端优先 WebGL；无法创建 WebGL 时，兼容画面仍投影真实三维几何并使用同一套游戏逻辑。
- `config.js` 中的 publishable key 是可公开的项目标识，不是服务端密钥。

## 验证

`node --test prop-hunt-source/tests/rules.test.js` 验证准备期、攻击额度与重置、重复事件、碰撞、命中即结束、超时、技能和交换攻守。另外通过在线验收脚本验证已部署房间API的创建、加入、满房、成员令牌、准备、开始、五次攻击与退出结算。

已完成云端API及双浏览器连通测试；中国大陆不同运营商的直连质量未经实地测试，不能据此保证全国线路均稳定。页面显示实时请求延迟。
